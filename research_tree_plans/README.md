# Research Tree Plans

Навигация по архитектурным планам для системы дерева исследований.

## Что лежит в папке

### 1. Info Panel

Файл: `01_info_panel.md`

О чем:
- вынос информативной панели из основного экрана
- `ResearchInfoContent`
- `ResearchInfoContent.Builder`
- отдельный `ResearchInfoPanel`
- подготовка к rewards, conditions и extra sections

Когда читать:
- если начинаешь рефакторить левую/правую панель деталей
- если нужно сделать builder для содержимого панели

---

### 2. Node Widgets

Файл: `02_node_widgets.md`

О чем:
- builder/factory для виджетов исследований
- визуальные пресеты нод
- иконки, бейджи, стили
- progress bar прямо на ноде
- отделение описания внешнего вида от UI-реализации

Когда читать:
- если нужно переделывать визуал исследований
- если хочется сделать переиспользуемое API для сборки нод

---

### 3. Unlock Animation On Open

Файл: `03_unlock_animation_on_open.md`

О чем:
- как показывать новые исследования не сразу, а при следующем открытии дерева
- seen-state / pending unlock animation
- переиспользование текущего unlock-animation pipeline
- подготовка к persisted cache

Когда читать:
- если нужно анимировать новые доступные исследования
- если нужно помнить, что игрок уже видел, а что нет

---

### 4. Tutorial And Assistant

Файл: `04_tutorial_and_assistant.md`

О чем:
- обучение при первом открытии
- tutorial steps и controller
- overlay для подсветки UI
- будущий ассистент-скрепка

Когда читать:
- если начинаешь делать onboarding
- если хочешь добавить пошаговый гайд по дереву исследований

---

## Рекомендуемый порядок реализации

1. `01_info_panel.md`
2. `02_node_widgets.md`
3. `03_unlock_animation_on_open.md`
4. `04_tutorial_and_assistant.md`

## Почему именно так

- сначала лучше стабилизировать панель деталей и сделать нормальную точку расширения
- потом вынести визуал самих нод в отдельную систему
- затем добавить отложенное unlock animation новых исследований
- и только после этого накладывать обучение и ассистента поверх уже чистой архитектуры

## Быстрый маршрут

Если коротко:
- хочешь начать рефактор UI -> `01_info_panel.md`
- хочешь улучшать карточки исследований -> `02_node_widgets.md`
- хочешь красивое появление новых исследований -> `03_unlock_animation_on_open.md`
- хочешь обучение и помощника -> `04_tutorial_and_assistant.md`
